### Q1
A company's web application lets customers sign in with their Google accounts. After sign-in, the application calls a REST API in Amazon API Gateway, and the API must validate a token that identifies the user. The company wants a managed user directory that also supports sign-up and MFA for customers who do not use Google. Which solution meets these requirements?

- A. Create an Amazon Cognito identity pool with Google as an identity provider and use it as the API Gateway authorizer.
- B. Create an Amazon Cognito user pool, add Google as a federated identity provider, and configure a Cognito user pool authorizer on the API.
- C. Create IAM users for each customer and enable IAM authorization on the API.
- D. Use AWS IAM Identity Center for customer sign-in.

> [!answer]- Answer
> **B.** A user pool is the user directory (sign-up, sign-in, MFA) and can federate social logins such as Google. It issues JWTs that the API Gateway user pool authorizer validates. An identity pool only exchanges identities for temporary AWS credentials; it is not an API Gateway authorizer. IAM Identity Center is for workforce users, not customers.
> 要点：用户目录 + 登录 + API 鉴权 → User Pool（社交登录也挂在 User Pool 上）。

### Q2
A public website shows a gallery of images stored in Amazon S3. Visitors who are not signed in must be able to read the images directly from S3 by using temporary, limited AWS credentials. Which solution meets this requirement?

- A. Create an Amazon Cognito user pool and require every visitor to sign up.
- B. Create an Amazon Cognito identity pool with unauthenticated (guest) access enabled, mapped to an IAM role that allows s3:GetObject on the gallery prefix.
- C. Embed an IAM user's access keys in the website's JavaScript.
- D. Configure a Cognito user pool authorizer on the S3 bucket.

> [!answer]- Answer
> **B.** Identity pools can issue temporary AWS credentials to unauthenticated guests through an IAM role with limited permissions. User pools do not issue AWS credentials and cannot be attached to S3. Never embed long-term keys in client code.
> 要点：临时 AWS 凭证（含访客）→ Identity Pool。

### Q3
Which of the following is NOT one of Amazon GuardDuty's foundational data sources?

- A. AWS CloudTrail management events
- B. VPC Flow Logs
- C. Route 53 DNS query logs
- D. Application Load Balancer access logs

> [!answer]- Answer
> **D.** GuardDuty's foundational data sources are CloudTrail management events, VPC Flow Logs, and DNS logs. Application-layer access logs (ALB, API Gateway, CloudFront, S3 server access, WAF) are not.
> 要点：谁调了 API / 流量去了哪 / 域名查了谁。

### Q4
A company wants to use EC2 hibernation so that an in-memory cache is still loaded after instances are stopped overnight and started in the morning. Which requirement must the instances meet?

- A. They must use an instance store root volume.
- B. Their root volume must be an encrypted EBS volume that is large enough to store the contents of RAM.
- C. They must be part of an Auto Scaling group.
- D. A new AMI must be created before each hibernation.

> [!answer]- Answer
> **B.** Hibernation writes RAM to the EBS root volume, so the root volume must be EBS, encrypted, and large enough for the RAM contents. An AMI only captures disk state, never memory.
> 要点：保留内存 → Hibernate（加密 EBS 根卷，空间够放 RAM）；AMI 不存内存。

### Q5
A company is moving a storage array to AWS. The array serves Windows file servers over SMB, Linux application servers over NFS, and a database cluster over iSCSI block storage. The company wants a single fully managed service with features such as snapshots and data deduplication. Which service should be used?

- A. Amazon FSx for Windows File Server
- B. Amazon EFS
- C. Amazon FSx for NetApp ONTAP
- D. Amazon FSx for Lustre

> [!answer]- Answer
> **C.** FSx for NetApp ONTAP supports SMB, NFS, and iSCSI from one file system, plus snapshots, deduplication, and compression. FSx for Windows is SMB, EFS is NFS only, and Lustre is for high-performance computing.
> 要点：多协议（SMB + NFS + iSCSI）→ ONTAP。

### Q6
A company stores 200 million objects of about 40 KB each in S3 Intelligent-Tiering. Most objects have not been accessed for six months. The finance team expected large savings but sees almost none. What is the MOST likely reason?

- A. Intelligent-Tiering charges a retrieval fee every time an object is read.
- B. Objects smaller than 128 KB are not eligible for auto-tiering and stay in the Frequent Access tier.
- C. Intelligent-Tiering bills each object as 128 KB in the Infrequent Access tier.
- D. Intelligent-Tiering only moves objects after 365 days.

> [!answer]- Answer
> **B.** Objects under 128 KB are never moved to cheaper tiers; they stay in Frequent Access and are billed at that rate. Intelligent-Tiering has no retrieval fees. "Billed as 128 KB" is the Standard-IA / Glacier IR rule, not Intelligent-Tiering.
> 要点：IT 是“不搬家”，IA 是“按 128 KB 罚钱”。

### Q7
Legal staff occasionally need a single document that is archived in S3 Glacier Flexible Retrieval. Requests must be fulfilled within one hour at the lowest possible cost. Which retrieval option should be used?

- A. Bulk
- B. Standard
- C. Expedited
- D. Copy the object to S3 Standard first by using a lifecycle rule

> [!answer]- Answer
> **C.** Only Expedited (1–5 minutes) meets a one-hour target. Standard is 3–5 hours and Bulk is 5–12 hours. Lifecycle rules cannot move objects back up from Glacier.
> 要点：加急按分钟（1–5 分），普通和批量按小时（3–5 时 / 5–12 时）。

### Q8
A company keeps compliance archives that are accessed about once a year. When an audit occurs, the data must be available within 6 hours. The company wants the lowest storage cost that meets this requirement. Which storage class should be used?

- A. S3 Glacier Deep Archive
- B. S3 Glacier Flexible Retrieval
- C. S3 Standard-IA
- D. S3 Glacier Instant Retrieval

> [!answer]- Answer
> **B.** Deep Archive is cheaper, but its fastest (Standard) retrieval takes up to 12 hours, which misses the 6-hour target. Glacier Flexible Retrieval's Standard retrieval (3–5 hours) meets it at the next-lowest storage price.
> 要点：Deep Archive 最快 12 小时；要求 12 小时以内 → 退到 Flexible。

### Q9
A team stores temporary exports in S3 One Zone-IA, and a lifecycle rule deletes them 20 days after creation. How many days of storage is each object billed for, and how quickly can it be read before deletion?

- A. 20 days; reads require a restore of 3–5 hours
- B. 30 days; reads in milliseconds
- C. 90 days; reads in milliseconds
- D. 30 days; reads require a restore of 1–5 minutes

> [!answer]- Answer
> **B.** One Zone-IA (like Standard-IA) has a 30-day minimum storage charge and returns objects in milliseconds. Only Glacier Flexible Retrieval and Deep Archive need a restore.
> 要点：30 / 90 / 180；IA 只是“不常访问”，不是“慢”。

### Q10
A network ACL has these inbound rules: rule 100 ALLOW TCP 443 from 0.0.0.0/0; rule 150 DENY all traffic from 203.0.113.0/24; rule * DENY all. A client at 203.0.113.25 sends an HTTPS request. What happens?

- A. The request is denied by rule 150.
- B. The request is allowed by rule 100.
- C. The request is denied because DENY rules always take priority.
- D. The request is allowed only if the security group also has a DENY rule.

> [!answer]- Answer
> **B.** NACL rules are evaluated in ascending order and the first match wins. Rule 100 matches first and allows the traffic, so rule 150 is never reached. To block the range, give the DENY a lower number (for example, 90).
> 要点：NACL 按编号从小到大，第一条命中就停；Deny 要编号更小。

### Q11
For which AWS services can you create a VPC gateway endpoint (as opposed to an interface endpoint)?

- A. Amazon S3 and Amazon DynamoDB
- B. Amazon S3, Amazon SQS, and Amazon SNS
- C. All AWS services
- D. Only Amazon S3

> [!answer]- Answer
> **A.** Gateway endpoints exist only for S3 and DynamoDB. They are added as targets in route tables and have no hourly or data processing charge. All other services use interface endpoints (AWS PrivateLink), which are billed per hour and per GB.
> 要点：网关终端节点只有 S3 和 DynamoDB，免费。

### Q12
EC2 instances in a private subnet used to reach S3 through a NAT gateway. The bucket policy allowed only the NAT gateway's Elastic IP by using aws:SourceIp. The team adds an S3 gateway endpoint to the route table, and uploads now fail with Access Denied. What should the team change?

- A. Add the instances' private IP addresses to the aws:SourceIp condition.
- B. Replace the aws:SourceIp condition with an aws:SourceVpce condition that matches the gateway endpoint ID.
- C. Remove the gateway endpoint; S3 cannot be reached privately.
- D. Attach an Elastic IP address to the gateway endpoint.

> [!answer]- Answer
> **B.** Traffic through a VPC endpoint no longer comes from the NAT gateway's public IP, so the aws:SourceIp condition no longer matches. Use aws:SourceVpce (or aws:SourceVpc) to allow only traffic through the endpoint.
> 要点：走 VPC 终端节点 → 用 aws:SourceVpce，不用 aws:SourceIp。

### Q13
A company encrypts a high-traffic S3 bucket with SSE-KMS using a customer managed key. Compliance requires the company to continue using that KMS key. AWS KMS request charges and the volume of KMS events in CloudTrail are both very high. Which solution addresses both problems?

- A. Switch the bucket's default encryption to SSE-S3.
- B. Enable S3 Bucket Keys on the bucket.
- C. Create a new KMS key each month.
- D. Use client-side encryption instead.

> [!answer]- Answer
> **B.** S3 Bucket Keys reduce calls from S3 to KMS, which lowers both KMS request costs and the number of KMS events in CloudTrail, while still using SSE-KMS with the same key. Switching to SSE-S3 or client-side encryption breaks the requirement to keep the KMS key.
> 要点：先核对硬性约束（must continue using the KMS key），再选。

### Q14
A software vendor uses CloudFront to distribute installers. When a customer buys a license, the vendor must give that customer a link to download one specific installer file that expires after 24 hours. Which solution meets this requirement?

- A. CloudFront signed cookies
- B. CloudFront signed URL
- C. An S3 presigned URL that bypasses CloudFront
- D. CloudFront geographic restrictions

> [!answer]- Answer
> **B.** A signed URL grants time-limited access to one file and is easy to send as a link. Signed cookies suit many files without changing URLs. An S3 presigned URL bypasses CloudFront.
> 要点：一个文件 → Signed URL；多个文件、不改 URL → Signed Cookies。
