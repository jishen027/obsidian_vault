# SAA-C03 生词本（英语词汇积累）

> 记录做 SAA-C03 模拟考题时遇到的、不认识或拿不准的英语单词/短语——这些词大多不是 AWS 专有名词（专有名词和服务概念记在 [[SAA-C03 模拟考错题本]] 和各服务笔记里），而是题干、选项、解析里常出现的**通用英语词汇**（法律/商业/技术描述类用词），认不全会拖慢做题速度、甚至因为读错题意而选错答案。
>
> 相关笔记：[[SAA-C03 模拟考错题本]]

---

## 使用方法

1. 做题/读解析时遇到不认识的词，直接把**单词 + 出现的那句原文（或题号）**发给我
2. 我会在下表按**字母顺序**插入一行：词性、中文释义、原句出处、以及（如果这个词在考试语境下有特定含义）一句"在这个场景下怎么理解"的说明
3. 定期（比如每积累 15-20 个词）通读一遍**词性+释义**列，遮住释义自测

## 生词表

| 单词/短语 | 词性  | 中文释义 | 例句/出处 | 考试语境下的理解 |
| ----- | --- | ---- | ----- | -------- |
| deteriorated | 动词（过去式/过去分词，原形 deteriorate） | 恶化、变差、退化 | 未提供例句/题号 | AWS 场景题里常用来描述**性能/体验随时间变差**，例如 "application performance has deteriorated"（应用性能变差了）——常见于需要排查瓶颈或做架构优化的题干开头 |
| delegate | 动词：委派、授权；名词：代表 | （动词）把某项权限/任务交给另一方去做 | 未提供例句/题号 | IAM/跨账户场景高频词，如 "delegate access to another AWS account"（把访问权限委派给另一个账户）——常与 IAM Role、Cross-account access、AssumeRole 一起出现，是 Domain 1（安全）题干里常见的动词 |

## 复习优先级（累积到一定数量后启用）

> 待生词表积累到 20+ 后，这里会分成两类整理：
> - **反复出现的高频词**（在多道题里都见过）——优先级最高，必须能脱口而出中文意思
> - **只出现过一次的生僻词**——按字母顺序过一遍即可，不必死记
