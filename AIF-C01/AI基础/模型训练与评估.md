## 数据集划分

> 将数据集划分为训练集、验证集和测试集，是保证模型评估客观性的关键。

### 三类数据集

| 数据集 | 用途 | 比例参考 |
|--------|------|---------|
| **训练集 (Training Set)** | 模型从中学习参数（权重） | 60–80% |
| **验证集 (Validation Set)** | 调整超参数，评估模型在训练过程中的表现 | 10–20% |
| **测试集 (Test Set)** | 最终评估模型在未见数据上的泛化能力 | 10–20% |

> **关键原则**：测试集只能在训练完成后使用一次，不能用于调参，否则会导致评估结果过于乐观。

### 交叉验证 (Cross-Validation)

> 数据量不足时，使用 K 折交叉验证充分利用数据。

```
K-Fold 交叉验证（K=5）
┌─────┬─────┬─────┬─────┬─────┐
│ 验证 │ 训练 │ 训练 │ 训练 │ 训练 │ 第1轮
│ 训练 │ 验证 │ 训练 │ 训练 │ 训练 │ 第2轮
│ 训练 │ 训练 │ 验证 │ 训练 │ 训练 │ 第3轮
│ 训练 │ 训练 │ 训练 │ 验证 │ 训练 │ 第4轮
│ 训练 │ 训练 │ 训练 │ 训练 │ 验证 │ 第5轮
└─────┴─────┴─────┴─────┴─────┘
最终得分 = 5 轮验证集准确率的平均值
```

## 训练核心概念

### 参数 vs 超参数（考试重点）

| 类型 | 定义 | 示例 | 谁来设置 |
|------|------|------|---------|
| **参数 (Parameters)** | 模型内部权重，训练中自动学习更新 | 神经网络权重、偏置项 | 算法自动优化 |
| **超参数 (Hyperparameters)** | 训练前手动配置的设置项 | 学习率、Epoch、批大小 | 工程师手动设定 |

### 关键超参数说明

| 超参数 | 描述 | 过大的影响 | 过小的影响 |
|--------|------|----------|----------|
| **学习率 (Learning Rate)** | 每次梯度更新的步长 | 不收敛，震荡 | 训练极慢，陷入局部最优 |
| **Epoch** | 训练数据被完整遍历的次数 | 过拟合 | 欠拟合 |
| **批大小 (Batch Size)** | 每次更新权重使用的样本数量 | 内存压力大，但梯度稳定 | 训练噪声大，但泛化性可能更好 |
| **层数/节点数** | 神经网络深度和宽度 | 过拟合、计算成本高 | 欠拟合，表达能力不足 |

### SageMaker 自动超参数调优

- **Automatic Model Tuning**（也称超参数调优 HPO）
- 自动搜索最优超参数组合
- 支持内置算法、自定义算法、预构建容器
- 可配合 **Spot 实例**节省成本

## 过拟合与欠拟合（考试重点）

| 状态 | 训练集表现 | 测试集表现 | 根本原因 |
|------|----------|----------|---------|
| **欠拟合 (Underfitting)** | 差 | 差 | 模型太简单，无法捕捉数据规律 |
| **过拟合 (Overfitting)** | 好 | 差 | 模型记住了训练噪声，泛化能力弱 |
| **泛化良好** | 好 | 好 | 目标状态 |

### 解决方案

| 问题 | 解决方案 |
|------|---------|
| **过拟合** | 增加训练数据、正则化（L1/L2）、Dropout、早停（Early Stopping）、减少模型复杂度 |
| **欠拟合** | 增加模型复杂度（更多层/节点）、增加训练 Epoch、特征工程 |

```
场景分析 → 诊断并解决
├── "训练集 95%，测试集 60%" → 过拟合 → 正则化 / 更多数据
├── "训练集 60%，测试集 58%" → 欠拟合 → 增加模型复杂度
└── "训练集 90%，测试集 88%" → 泛化良好 ✅
```

## 分类任务评估指标（考试重点）

### 混淆矩阵

```
                预测：正 (Positive)   预测：负 (Negative)
实际：正 (P)   TP（真正例）           FN（假负例 / 漏报）
实际：负 (N)   FP（假正例 / 误报）    TN（真负例）
```

| 指标 | 公式 | 重点场景 |
|------|------|---------|
| **准确率 (Accuracy)** | (TP + TN) / 总数 | 类别均衡时使用 |
| **精确率 (Precision)** | TP / (TP + FP) | 降低误报成本（垃圾邮件过滤） |
| **召回率 (Recall)** | TP / (TP + FN) | 降低漏报成本（癌症筛查） |
| **F1 分数** | 2 × P × R / (P + R) | 类别不均衡时使用，兼顾精确率和召回率 |
| **AUC-ROC** | ROC 曲线下面积（0~1） | 综合评估二分类模型整体表现 |

### Precision vs Recall 选择逻辑

```
业务场景 → 选择侧重指标
├── "误报代价高（把正常邮件标为垃圾）" → 提高 Precision（减少 FP）
├── "漏报代价高（漏诊癌症）" → 提高 Recall（减少 FN）
└── "两者都重要，数据不均衡" → 使用 F1 分数
```

## 回归任务评估指标

| 指标 | 全称 | 描述 |
|------|------|------|
| **MAE** | 平均绝对误差 | 预测值与真实值差的绝对值均值，直观易理解 |
| **MSE** | 均方误差 | 差值平方的均值，对大误差惩罚更重 |
| **RMSE** | 均方根误差 | MSE 的平方根，与原始单位一致 |
| **R²** | 决定系数 | 模型解释目标变量方差的比例（0~1，越高越好） |

## NLP 评估指标（考试重点）

| 指标 | 全称 | 评估对象 | 核心原理 |
|------|------|---------|---------|
| **BLEU** | Bilingual Evaluation Understudy | 机器翻译 | 基于 n-gram 精确率匹配 |
| **ROUGE** | Recall-Oriented Understudy for Gisting Evaluation | 文本摘要 | 基于 n-gram 召回率匹配 |
| **METEOR** | Metric for Evaluation of Translation with Explicit ORdering | 翻译/摘要 | 考虑同义词、词形变化，比 BLEU 更全面 |
| **BERTScore** | — | 语义相似度 | 使用 BERT 编码器计算语义相似度（而非字面匹配） |
| **Perplexity** | 困惑度 | 语言模型质量 | 越低越好，表示模型对测试集的预测越准确 |

### LLM 专用评估指标

| 指标 | 描述 |
|------|------|
| **事实性 (Factuality)** | 输出是否与事实相符（对抗幻觉） |
| **相关性 (Relevance)** | 回答是否与问题相关 |
| **连贯性 (Coherence)** | 输出文本逻辑是否连贯 |
| **毒性 (Toxicity)** | 输出是否包含有害内容 |

## 图像/生成模型评估指标

| 指标 | 描述 | 越高/低越好 |
|------|------|-----------|
| **PSNR（峰值信噪比）** | 衡量图像重建质量，信号与噪声的比率 | 越高越好 |
| **SSIM（结构相似性）** | 从亮度、对比度、结构三个维度评估图像相似度 | 越高越好（最大值 1） |
| **IoU（交并比）** | 目标检测中预测框与真实框的重叠程度 | 越高越好（最大值 1） |
| **Inception Score** | 评估 GAN 生成图像的真实感与多样性 | 越高越好 |
| **FID（Fréchet Inception Distance）** | 评估真实图像与生成图像的分布距离 | 越低越好 |

```

              ↓                ↓

              ↓                ↓
         重新训练         是 → 部署  否 → 重新训练
```

## 考试重点总结

### AIF-C01 高频考点

1. **数据集划分**：训练集（学习）/ 验证集（调参）/ 测试集（最终评估）
2. **参数 vs 超参数**：自动学习 vs 手动设置
3. **过拟合 vs 欠拟合**：通过训练集/测试集表现差距判断
4. **F1 分数**：类别不均衡时比 Accuracy 更准确
5. **BLEU/ROUGE**：翻译/摘要的评估指标
6. **NLP 指标区别**：BLEU（精确率方向）/ ROUGE（召回率方向）

### 场景题解题思路

```
场景分析 → 选择评估指标
├── "评估机器翻译质量" → BLEU
├── "评估文本摘要质量" → ROUGE
├── "类别严重不均衡的分类问题" → F1 分数
├── "癌症筛查，不能漏诊" → 最大化 Recall
├── "垃圾邮件过滤，不能误判" → 最大化 Precision
├── "评估图像生成质量" → PSNR / SSIM / FID
└── "目标检测预测框准确度" → IoU（交并比）
```
