# 深度学习与神经网络

> **深度学习 (Deep Learning)** 是使用多层神经网络处理复杂特征的机器学习子领域。当数据复杂、特征不明确时，深度学习比传统 ML 更有优势。它是 LLM 和生成式 AI 的核心技术基础。

## 神经网络基础

### 大脑类比

> 深度学习的灵感来源于**人类大脑**的工作方式。大脑中由称为"**神经元 (Neurons)**"的脑细胞形成复杂网络，相互发送电信号来处理信息。深度学习使用被称为"**节点 (Nodes)**"的软件模块来模拟神经元的行为。

| 大脑 | 深度学习模型 |
|------|------------|
| 神经元 (Neuron) | 节点 (Node) |
| 神经元之间的连接 | 节点之间的权重 (Weight) |
| 电信号传递 | 数值向前传播 |
| 学习和记忆 | 训练中的权重调整 |

### 感知器 (Perceptron)

> **感知器** 是神经网络的最基础单元，于 1943 年提出，1957 年制造出物理机器（Mark I Perceptron）。

- 最早的二元分类器（监督学习）
- 能执行简单图像识别
- 多个感知器堆叠形成神经网络（多层感知器 MLP）

### 神经网络结构

```
输入层 (Input Layer) → 隐藏层 1 → 隐藏层 2 → ... → 输出层 (Output Layer)
      ↓                    ↓            ↓                      ↓
   输入特征            权重×激活      权重×激活              预测结果
```

| 层类型 | 描述 |
|--------|------|
| **输入层** | 接收原始特征数据 |
| **隐藏层** | 学习中间特征表示，层数越多越"深" |
| **输出层** | 产生最终预测结果 |
| **节点 (Node)** | 每层中的处理单元，每个节点自主为每个特征分配权重 |
| **权重 (Weight)** | 节点之间连接的强度，训练中更新 |

### 训练流程

```
输入数据 → 前向传播（产生预测输出）→ 计算预测与实际的差异（误差）
                                                    ↓
                               反向传播（调整权重）← 最小化误差 ← 重复迭代
```

### 云计算与深度学习的普及

> 神经网络的概念早已存在，但在**低成本云计算**问世之前，大多数企业无法获得训练深度学习所需的巨大计算能力。现在任何人都可以在云端轻松使用强大的 GPU 资源，**神经网络已成为计算机视觉的标准算法**。

### 深度学习 vs 传统 ML

| 特性 | 传统 ML | 深度学习 |
|------|---------|---------|
| **特征工程** | 需要人工设计特征 | 自动学习特征（自主识别模式） |
| **数据需求** | 相对较少 | 需要大量数据（可能需数百万样本） |
| **计算需求** | 较低 | 高（GPU 加速，基础设施成本明显更高） |
| **可解释性** | 较好 | 差（黑盒） |
| **数据类型** | 结构化、标注数据 | 非结构化数据（图像、视频、文本） |
| **统计算法** | 是 | 是（区别在于使用神经网络） |

### 何时选择传统 ML vs 深度学习

| 场景特征 | 选择 | 示例 |
|---------|------|------|
| **结构化 + 标注数据，特征清晰** | 传统 ML（高效） | 手机公司根据历史客户流失数据预测客户何时换运营商 |
| **非结构化数据，复杂关系** | 深度学习 | 分析社交媒体提及次数或产品反馈，确定用户情绪 |
| **图像、视频任务** | 深度学习（CNN） | 计算机视觉：对象检测、图像分类 |
| **NLP 任务** | 深度学习（Transformer/LLM） | 文本理解、情感分析、语言翻译 |
| **推荐系统、分类** | 传统 ML 通常足够 | 产品推荐、垃圾邮件过滤 |

## 激活函数

> **激活函数** 决定神经元是否被激活，引入非线性以使网络能学习复杂模式。

| 激活函数 | 特点 | 适用场景 |
|---------|------|---------|
| **Sigmoid** | S 形曲线，输出 0-1 之间 | 二分类输出层，Logistic 回归 |
| **ReLU (修正线性单元)** | 负值为 0，正值线性输出 | 隐藏层最常用，解决梯度消失 |
| **Leaky ReLU** | 负值有微小斜率（不完全为 0） | 防止神经元"死亡" |
| **Parametric ReLU** | 负斜率为可学习参数 | Leaky ReLU 的改进版 |
| **ELU (指数线性单元)** | 负值趋向 -1 的平滑曲线 | 平滑 ReLU 的缺陷 |
| **Softmax** | 多类别概率输出（总和=1） | 多分类输出层 |

## 常见神经网络类型

| 网络类型 | 缩写 | 特点 | 适用场景 |
|---------|------|------|---------|
| **卷积神经网络** | CNN | 局部连接，参数共享，擅长空间特征 | 图像识别、视频分析 |
| **循环神经网络** | RNN | 有时间记忆，处理序列数据 | 文本、语音、时间序列 |
| **生成对抗网络** | GAN | 生成器 vs 判别器对抗训练 | 图像生成、风格迁移 |
| **自编码器** | Autoencoder | 编码压缩 + 解码重建 | 降维、异常检测、去噪 |
| **多层感知器** | MLP | 全连接层堆叠 | 通用分类、回归 |
| **Transformer** | — | 注意力机制，并行处理 | NLP、LLM（见专项笔记） |

## 模型训练基础

### 训练流程

```
准备数据集 → 初始化权重 → 前向传播 → 计算损失 → 反向传播 → 更新权重 → 重复
```

### 关键训练概念

| 概念 | 描述 |
|------|------|
| **前向传播 (Forward Pass)** | 数据从输入层流向输出层，产生预测 |
| **损失函数 (Loss Function)** | 衡量预测结果与真实标签的差距 |
| **反向传播 (Backpropagation)** | 根据损失计算梯度，从输出层反向更新权重 |
| **梯度下降 (Gradient Descent)** | 沿梯度反方向更新权重，最小化损失 |
| **批次 (Batch)** | 每次更新权重使用的数据子集 |
| **Epoch** | 完整遍历训练集一次 |
| **学习率 (Learning Rate)** | 每次权重更新的步长大小 |

## 评估指标（考试重点）

### 分类评估指标

| 指标 | 公式 | 描述 |
|------|------|------|
| **准确率 (Accuracy)** | 正确预测数 / 总预测数 | 整体正确率（适用于均衡数据集） |
| **精确率 (Precision)** | TP / (TP + FP) | 预测为正的样本中真正为正的比例 |
| **召回率 (Recall)** | TP / (TP + FN) | 实际为正的样本中被正确找出的比例 |
| **F1 分数** | 2 × (P × R) / (P + R) | 精确率与召回率的调和平均值 |

> **F1 分数** 在类别不均衡（Imbalanced）时比 Accuracy 更有参考价值，当假阴性和假阳性同样重要时使用。

### 混淆矩阵

```
                预测：正       预测：负
实际：正    TP (真正例)    FN (假负例)
实际：负    FP (假正例)    TN (真负例)
```

### 图像评估指标

| 指标 | 用途 |
|------|------|
| **PSNR (峰值信噪比)** | 衡量图像重建质量（信号与噪声比） |
| **SSIM (结构相似性)** | 测量两张图像的视觉相似度 |
| **IoU (交并比)** | 测量目标检测中预测框与真实框的重叠度 |
| **Inception Score** | 评估 GAN 生成图像的真实感 |

### NLP 评估指标

| 指标 | 全称 | 描述 |
|------|------|------|
| **BLEU** | Bilingual Evaluation Understudy | 基于 n-gram 匹配评估机器翻译质量 |
| **ROUGE** | Recall-Oriented Understudy for Gisting Evaluation | 评估文本摘要质量，侧重召回率 |
| **METEOR** | Metric for Evaluation of Translation with Explicit Ordering | 改进版翻译评估，考虑同义词 |
| **BERTScore** | — | 基于 BERT 语义相似度的评估指标 |

## 深度学习考试重点

### 常见网络对应场景

```
场景分析 → 选择网络类型
├── "图像分类/识别" → CNN（卷积神经网络）
├── "文本/语音序列处理" → RNN（循环神经网络）
├── "生成逼真图像" → GAN（生成对抗网络）
├── "数据压缩/异常检测" → Autoencoder（自编码器）
└── "自然语言处理/LLM" → Transformer
```

### AIF-C01 高频考点

1. **深度学习 = 神经网络**：数据复杂、特征不明确时使用
2. **CNN**：图像任务首选
3. **RNN**：序列数据（文本、时间序列）；但 Transformer 已在 NLP 中取代 RNN
4. **GAN**：生成逼真图像
5. **激活函数**：ReLU 最常用于隐藏层，Softmax 用于多分类输出
6. **评估指标**：F1 用于不均衡数据，BLEU/ROUGE 用于 NLP 任务
7. **传统 ML vs 深度学习**：结构化数据→传统 ML；非结构化/复杂关系→深度学习
8. **云计算普及意义**：使企业能够以低成本访问神经网络所需的计算资源
9. **节点自主分配权重**：深度学习不需要人工进行特征工程
