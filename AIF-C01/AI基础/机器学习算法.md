## ML 问题类型识别框架（考试重点）

> 拿到一个 ML 问题，先判断数据集是否有标签，再判断目标值类型。

```
数据集是否包含标签（目标值）？
├── 有标签（有监督学习）
│   ├── 目标值是离散分类？ → 分类问题 (Classification)
│   │   ├── 两个互斥类别？ → 二元分类 (Binary)
│   │   └── 多个类别？ → 多元分类 (Multi-class)
│   └── 目标值是连续数值？ → 回归问题 (Regression)
│       ├── 预测连续值（线性关系）→ 线性回归
│       └── 预测事件概率（0~1）→ 逻辑回归
└── 无标签（无监督学习）
    ├── 将数据分成离散组？ → 聚类 (Clustering)
    └── 发现数据中的异常值？ → 异常检测 (Anomaly Detection)
```

## 监督学习算法

### 回归 (Regression)

> **回归** 是根据一个或多个与因变量相关的其他变量/属性，来估算因变量（目标变量）值的过程。目标值在数学上是**连续的**。

| 特性 | 描述 |
|------|------|
| **输出类型** | 连续数值（如价格、温度、销量） |
| **典型场景** | 房价预测、天气预测、股价预测 |
| **常见算法** | 线性回归、多项式回归、Ridge/Lasso |

#### 回归类型对比

| 类型 | 自变量数量 | 输出 | 示例 |
|------|----------|------|------|
| **简单线性回归** | 1 个 | 连续值 | 用**体重**预测**身高** |
| **多元线性回归** | 多个 | 连续值 | 用**体重 + 年龄**预测身高；用**卧室数、浴室数、面积**预测房价 |
| **逻辑回归** | 1 个或多个 | 概率（0~1） | 用 BMI + 吸烟状况 + 遗传倾向预测是否患心脏病；预测金融交易是否为欺诈 |

#### 逻辑回归（Logistic Regression）

> **逻辑回归**用于衡量事件发生的概率，使用对数函数计算回归线，输出介于 **0 和 1 之间**。

- **0** → 事件不太可能发生
- **1** → 事件最有可能发生
- 尽管名称包含"回归"，但实际上用于**分类**（预测概率后设置阈值判断类别）
- 示例 1：根据 BMI、吸烟状况、遗传倾向 → 预测一个人是否会患心脏病
- 示例 2：根据交易特征 → 预测金融交易是否为欺诈（训练数据标注为"欺诈"/"非欺诈"）

> 线性回归和逻辑回归都需要**大量标注数据**才能确保模型预测的准确率。

#### 线性回归训练示例

> **线性回归**：寻找与输入数据最佳拟合的直线，找到自变量与因变量之间的线性关系。

**方程**：`y = mx + b`（例：`身高 = m × 体重 + b`）

| 元素 | 含义 | 由谁决定 |
|------|------|---------|
| `m`（斜率） | 模型参数，决定直线倾斜程度 | 训练中迭代自动学习 |
| `b`（截距） | 模型参数，决定直线与纵轴的交点 | 训练中迭代自动学习 |
| `x`（输入特征） | 自变量（如体重） | 输入数据提供 |
| `y`（预测输出） | 因变量（如身高） | 模型计算输出 |

**训练目标**：找到使**误差最小化**的 `m` 和 `b` 值——误差即数据点与直线之间的距离（残差）。

```
训练过程
→ 初始化参数 m, b
→ 前向传播：计算预测值 ŷ = mx + b
→ 计算误差（预测值与真实值的差距）
→ 反向传播：调整 m 和 b 减小误差
→ 重复迭代，直到误差收敛（最佳拟合）
→ 推理：用训练好的 m, b 对新输入 x 预测 y
```

### 分类 (Classification)

> **分类** 是将输入分配到预定义类别（离散值）的过程。

| 特性 | 描述 |
|------|------|
| **输出类型** | 离散类别（如猫/狗/鸟、垃圾邮件/正常） |
| **典型场景** | 图像分类、垃圾邮件过滤、医疗诊断 |
| **常见算法** | 逻辑回归、SVM、决策树、随机森林 |

#### 二元分类 vs 多元分类

| 类型 | 描述 | 示例 |
|------|------|------|
| **二元分类 (Binary)** | 将输入分配到**两个**互斥预定义类别之一 | 根据诊断测试判断是否患病（患病/未患病）；鱼 vs 非鱼 |
| **多元分类 (Multi-class)** | 将输入分配到**多个**类别之一 | 预测文本文档的主题（宗教/政治/金融/其他）；识别多种海洋生物类别 |

### 回归 vs 分类（考试高频对比）

| 特性 | 回归 | 分类 |
|------|------|------|
| **预测目标** | 连续数值 | 离散类别 |
| **输出示例** | 价格 $350,000 | 猫 / 狗 / 鸟 |
| **评估指标** | MSE、RMSE、R² | 准确率、F1、AUC |
| **典型算法** | 线性回归 | 逻辑回归、SVM |

### K 近邻 (KNN)

> **KNN** 本身不是 ML，但当应用于解决 ML 问题时成为 ML 算法。通过找到"最近的 K 个邻居"来预测。

- 适用于分类和回归
- 计算简单，无需训练阶段
- 对高维数据效率较低

## 无监督学习算法

### 聚类 (Clustering)

> **聚类**是将数据对象分为称为"聚类"的组的分类技术。组内成员尽可能彼此相似，与其他组成员尽可能不同。

**配置聚类需要定义**：
1. 用于确定相似性的**特征或属性**
2. 衡量相似性的**距离函数**
3. 要分析的**聚类数量**

| 算法 | 特点 | 场景 |
|------|------|------|
| **K-Means** | 将数据分为 K 个簇，迭代更新中心点 | 客户分群、文档聚类 |
| **层次聚类** | 构建树形结构的聚类层次 | 基因数据分析 |
| **DBSCAN** | 基于密度，能发现任意形状的簇 | 异常检测、地理数据 |

- **示例**：按购买历史记录或点击流活动将客户分组

### 异常检测 (Anomaly Detection)

> **异常检测**识别数据中会引起怀疑的小概率项目、事件或观测结果，因为它们与其余数据存在显著差异。

| 特性 | 描述 |
|------|------|
| **学习类型** | 无监督学习（无需标注，模型学习正常模式后检测偏差） |
| **输出** | 标记出异常值/异常事件 |
| **典型场景** | 欺诈检测、设备传感器故障、医疗失误检测、网络安全入侵 |

- **示例 1**：识别传感器报告数据远超正常范围 → 判断传感器可能出现故障
- **示例 2**：网络流量聚类后发现异常流量 → 预测潜在安全事件

### 关联规则 (Association)

> 发现数据中共现的规律，即"经常一起出现的事物"。

- **典型场景**：购物篮分析（买尿布的人也买啤酒）
- **核心指标**：支持度（Support）、置信度（Confidence）、提升度（Lift）
- **典型算法**：Apriori、FP-Growth

### 降维 (Dimensionality Reduction)

> 在保持数据核心信息的前提下，减少特征（维度）数量，常用于数据预处理阶段。

| 算法 | 全称 | 特点 |
|------|------|------|
| **PCA** | 主成分分析 | 最常用，线性降维 |
| **LDA** | 线性判别分析 | 考虑类别标签的降维 |
| **SVD** | 奇异值分解 | 矩阵分解，用于推荐系统 |

## 强化学习

> **强化学习**：Agent 在 Environment 中执行 Action，根据 Reward/Penalty 反馈学习最优 Policy。

```
Agent → Action → Environment → Reward/Penalty → Agent (学习更新)
```

| 组成 | 描述 |
|------|------|
| **Agent** | 执行决策的学习主体 |
| **Environment** | Agent 交互的环境 |
| **Action** | Agent 可以执行的操作 |
| **Reward** | 环境对 Action 的正向反馈 |
| **Penalty** | 环境对 Action 的负向反馈 |
| **Policy** | Agent 的决策策略（输入状态 → 输出动作） |

- **典型场景**：游戏 AI（围棋 AlphaGo）、机器人控制、自动驾驶
- **与 Agentic AI 的关联**：Bedrock Agents 的设计理念借鉴了强化学习中 Agent 的概念

## 模型参数与超参数

> 理解训练时调整的参数是理解 ML 流程的基础。

| 概念 | 定义 | 由谁决定 |
|------|------|---------|
| **参数 (Parameters)** | 模型内部权重，训练过程中自动学习 | 模型训练自动更新 |
| **超参数 (Hyperparameters)** | 训练前手动设置的配置项 | 工程师手动设定 |

### 关键超参数

| 超参数 | 描述 | 影响 |
|--------|------|------|
| **学习率 (Learning Rate)** | 每次更新权重的步长大小 | 过大→不收敛，过小→训练慢 |
| **Epoch** | 训练数据集被完整遍历的次数 | 过多→过拟合，过少→欠拟合 |
| **批大小 (Batch Size)** | 每次更新权重使用的样本数 | 影响训练速度和内存占用 |

### SageMaker 自动调参

- **SageMaker Automatic Model Tuning**（也称超参数调优）
- 自动搜索最优超参数组合
- 可使用 Spot 实例节省成本
- 适用于内置算法、自定义算法、预构建容器

## 过拟合与欠拟合（考试重点）

| 状态 | 描述 | 表现 | 解决方案 |
|------|------|------|---------|
| **过拟合 (Overfitting)** | 模型过度学习训练数据的噪声 | 训练集准确高，测试集准确低 | 增加数据、正则化、Dropout、减少模型复杂度 |
| **欠拟合 (Underfitting)** | 模型过于简单，无法捕捉规律 | 训练集和测试集准确都低 | 增加模型复杂度、增加训练时间、特征工程 |
| **泛化良好** | 在未见数据上也有良好表现 | 训练集和测试集准确相近 | 目标状态 |

```
场景分析 → 诊断模型问题
├── "训练好，测试差" → 过拟合 → 正则化、更多数据
├── "训练和测试都差" → 欠拟合 → 增加模型复杂度
└── "训练和测试都好" → 泛化良好 ✅
```

## 考试重点总结

### AIF-C01 高频考点

1. **ML 问题类型识别**：有标签→监督学习；无标签→无监督学习
2. **监督学习**：回归（连续数值）vs 分类（离散类别）
3. **二元 vs 多元分类**：两类互斥 vs 多类别之一
4. **线性回归 vs 逻辑回归**：预测连续值 vs 预测概率（0~1）
5. **无监督学习**：聚类（分群）、异常检测（找偏差）、关联（共现规律）、降维（减少特征）
6. **聚类配置三要素**：相似性特征、距离函数、聚类数量
7. **强化学习**：Agent + Environment + Reward 机制
8. **超参数 vs 参数**：手动设置 vs 训练中自动学习
9. **过拟合 vs 欠拟合**：训练集/测试集性能差距

### 场景题解题思路

```
场景分析 → 选择算法类型
├── "预测未来价格/数量" → 回归
├── "识别属于哪个类别" → 分类
├── "将客户自动分组" → 聚类（无监督）
├── "发现商品关联规律" → 关联规则
├── "减少数据维度" → 降维（PCA）
└── "Agent 学习最优策略" → 强化学习
```
