# AI 与机器学习基础概念

> **人工智能 (AI)** 是一个宽泛术语，指让机器模拟人类智能的技术。机器学习 (ML) 是 AI 的子集，生成式 AI 是 ML 的子集。理解它们之间的层级关系是 AIF-C01 的核心基础。
>
> 相关文档：[[机器学习算法]] | [[深度学习与神经网络]] | [[大语言模型 - LLM]] | [[AIF-C01 考试概览]]

---

## 核心概念层级

### AI / ML / 深度学习 / 生成式 AI 的关系

```
人工智能 (AI) ← 宽泛概念
└── 机器学习 (ML) ← 通过数据学习，无需明确编程
    └── 深度学习 (Deep Learning) ← 使用神经网络
        └── 生成式 AI (Generative AI) ← 能生成新内容
            └── 大语言模型 (LLM) ← 文本生成的子集
```

### 定义对比

| 概念 | 定义 | 关键特征 |
|------|------|---------|
| **AI (人工智能)** | 机器模拟人类智能的技术总称 | 宽泛术语，包含所有子领域 |
| **ML (机器学习)** | 机器通过数据自动改善任务表现，无需明确编程 | 有算法、有数据、有学习过程 |
| **深度学习** | 使用多层神经网络处理复杂特征的 ML 子领域 | 数据复杂时使用，特征不明确时使用 |
| **生成式 AI** | 能生成新内容（文本、图像、音频等）的 AI | 多模态输出 |
| **LLM** | 生成类人文字的大型语言模型，是生成式 AI 的子集 | 文本模态，基于 NLP |

## 三种机器学习类型（考试重点）

### 类型对比

| 类型 | 数据特征 | 典型算法 | 适用场景 |
|------|---------|---------|---------|
| **监督学习 (Supervised)** | **有标签数据** | 回归、分类、决策树、SVM | 价格预测、垃圾邮件过滤、图像分类 |
| **无监督学习 (Unsupervised)** | **无标签数据** | 聚类、关联规则、降维 | 客户分群、市场篮子分析、异常检测 |
| **强化学习 (Reinforcement)** | 环境反馈 (奖惩) | Q-Learning、策略梯度 | 游戏 AI、机器人控制、推荐系统 |

### 监督学习 vs 无监督学习（考试高频对比）

| 特性 | 监督学习 | 无监督学习 |
|------|---------|----------|
| **数据需求** | 需要人工标注标签 | 不需要标签 |
| **准确性** | 通常更高 | 较低，仍需人工验证 |
| **前期工作** | 多（数据标注成本高） | 少 |
| **结果** | 预测已知类别 | 发现未知模式 |
| **关键词** | "分类"、"预测数值" | "分群"、"发现规律" |

> **强化学习**：Agent 在 Environment 中行动，通过反馈（奖励/惩罚）学习最优策略。类似于 Agentic AI 工作流的理念基础。

## 模态 (Modalities)

> **模态** 指模型能感知和生成的内容类型，类比人类的感觉器官。

| 模态 | 示例 | 相关服务 |
|------|------|---------|
| **文本 (Text)** | 生成文章、翻译、摘要 | LLM、Amazon Comprehend |
| **图像 (Vision)** | 图像生成、对象识别 | Stable Diffusion、Amazon Rekognition |
| **音频 (Audio)** | 语音识别、音乐生成 | Amazon Transcribe、Amazon Polly |
| **视频 (Video)** | 视频分析、动作识别 | Amazon Rekognition Video |
| **分子 (Molecular)** | 药物发现、基因组数据分析 | 专业科学 AI 模型 |

> LLM 主要是**文本模态**，但现代 LLM 正在演进为**多模态 (Multimodal)**，可跨模态处理。

## NLP (自然语言处理)

> **NLP (Natural Language Processing)** 是 ML 中理解和处理人类语言的技术，交汇于计算机科学与语言学。

### NLP 核心任务

| 任务 | 描述 | AWS 服务 |
|------|------|---------|
| **情感分析 (Sentiment Analysis)** | 判断文本正面/负面/中性 | Amazon Comprehend |
| **实体识别 (NER)** | 提取人名、地名、组织等实体 | Amazon Comprehend |
| **文本分类 (Classification)** | 将文本归入预定义类别 | Amazon Comprehend |
| **机器翻译 (Translation)** | 语言之间的文本翻译 | Amazon Translate |
| **语音识别 (ASR)** | 将语音转为文字 | Amazon Transcribe |
| **文本生成 (Generation)** | 生成连贯的自然语言文本 | Amazon Bedrock (LLM) |
| **问答 (Q&A)** | 基于上下文回答问题 | Amazon Kendra / Bedrock |

### 关键 NLP 术语

| 术语 | 定义 |
|------|------|
| **语料库 (Corpus)** | 用于训练的相关文本集合 |
| **Token (词元)** | 文本被分割的最小单位（词或子词） |
| **Tokenization** | 将文本分割成 Token 序列的过程 |
| **Embedding** | 将文本转换为数值向量的表示 |

## 数据生命周期 (CRISP-DM)

> **CRISP-DM** 是经典的数据挖掘跨行业标准流程，定义了 ML 项目的完整生命周期。

```
业务理解 → 数据理解 → 数据准备 → 建模 → 评估 → 部署
(Business)   (Data       (Data        (Modeling) (Evaluation) (Deployment)
             Understanding) Preparation)
```

### 各阶段说明

| 阶段 | 核心问题 | 关键活动 |
|------|---------|---------|
| **业务理解** | 业务需要什么？ | 定义目标、成功标准 |
| **数据理解** | 我们有什么数据？ | 数据探索、质量评估 |
| **数据准备** | 如何整理数据？ | 清洗、转换、特征工程 |
| **建模** | 使用什么算法？ | 选择模型、训练、调参 |
| **评估** | 模型够好吗？ | 性能指标评估、业务目标验证 |
| **部署** | 如何让人使用？ | 模型部署、监控、维护 |

### 数据准备步骤

| 步骤 | 描述 |
|------|------|
| **结构化 (Structuring)** | 将内容整理成便于处理的格式 |
| **清洗 (Cleaning)** | 移除异常值、填充空值、去除重复项 |
| **丰富 (Enriching)** | 从外部来源追加相关上下文数据 |
| **验证 (Validating)** | 验证数据的真实性与合规性 |

## AI 工程师 vs 数据科学家

| 角色 | 职责 | 技能侧重 |
|------|------|---------|
| **AI 工程师** | 使用托管 AI 服务构建 AI 解决方案 | API 集成、MLOps、应用开发 |
| **数据科学家** | 研究数据、构建和训练 ML 模型 | 统计学、Python、数学、ML 算法 |

> AIF-C01 更偏向 AI 工程师视角（使用服务），而非深入的数学推导。

## 考试重点总结

### AIF-C01 高频考点

1. **AI/ML/深度学习/生成式 AI 的层级关系**
2. **三种学习类型**：监督（标签数据）/ 无监督（无标签）/ 强化（奖惩反馈）
3. **NLP 概念**：语料库、Tokenization、Embedding
4. **模态**：文本、图像、音频、视频
5. **CRISP-DM 流程**：业务理解 → 数据准备 → 建模 → 评估 → 部署

### 场景题解题思路

```
场景分析 → 选择学习类型
├── "有标注数据，预测类别/数值" → 监督学习
├── "无标注数据，发现模式/分群" → 无监督学习
├── "Agent 与环境交互，通过反馈学习" → 强化学习
├── "识别图像中的对象" → 计算机视觉（监督学习）
└── "分析文字情感/提取实体" → NLP（监督学习）
```
