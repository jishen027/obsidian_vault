# AWS AI 托管服务

> AWS 提供一系列开箱即用的 AI 服务，覆盖计算机视觉、NLP、对话 AI、推荐系统等领域。这些服务通过 API 调用即可使用，无需 ML 专业知识。是 AIF-C01 考试 Domain 1 和 Domain 3 的重要考点。
>
> 相关文档：[[Amazon Bedrock]] | [[Amazon SageMaker]] | [[AI与ML概念]] | [[AIF-C01 考试概览]]

| 类别 | 服务 | 核心功能 |
|------|------|---------|

## Amazon Rekognition（计算机视觉）

> **Amazon Rekognition** 是深度学习驱动的图像和视频分析服务，无需 ML 背景即可使用。

### 核心功能

| 功能 | 描述 |
|------|------|
| **对象/场景检测** | 识别图像中的物体、场景、活动 |
| **人脸检测/分析** | 检测人脸，分析年龄、情感、眼镜等属性 |
| **人脸比对** | 比较两张图片中的人脸是否为同一人 |
| **名人识别** | 识别图像中的公众人物 |
| **文字识别 (OCR)** | 提取图像中的文字内容 |
| **内容审核** | 检测不雅、暴力等不适合内容 |
| **视频分析** | 分析视频流中的动作、人物、对象 |

### 适用场景

```
场景分析 → 使用 Rekognition
├── "验证用户身份（人脸识别）" → Rekognition Face Comparison
├── "审查用户上传图片是否合规" → 内容审核
├── "从图片中提取文字" → Rekognition Text Detection
└── "识别视频中出现的人物" → 名人识别 / 人脸识别
```

## Amazon Comprehend（NLP 文本分析）

> **Amazon Comprehend** 使用 NLP 分析文本，提取关键信息，支持自定义模型。

### 核心功能

| 功能 | 描述 |
|------|------|
| **情感分析 (Sentiment Analysis)** | 判断文本的情感倾向：正面、负面、中性、混合 |
| **实体识别 (Entity Recognition)** | 提取人名、地名、日期、组织、数量等实体 |
| **关键短语提取** | 识别文本中的关键词组 |
| **语言检测** | 自动检测文本使用的语言 |
| **PII 检测** | 识别个人身份信息（姓名、电话、邮件、信用卡等） |
| **目标情感 (Targeted Sentiment)** | 针对特定实体的情感分析 |
| **自定义实体/分类** | 训练自定义 NLP 模型识别领域专有实体或分类 |

### Comprehend Flywheel

- **Flywheel** 是 Comprehend 的子服务，自动化自定义模型版本的持续训练（类似持续学习）

### 适用场景

```
场景分析 → 使用 Comprehend
├── "分析客户评论的正负面情绪" → 情感分析
├── "从合同中提取公司名称和日期" → 实体识别
├── "检查文档中是否包含个人信息" → PII 检测
└── "将客户支持工单自动分类" → 自定义分类
```

## Amazon Textract（文档 OCR）

> **Amazon Textract** 超越传统 OCR，不仅提取文字，还理解文档结构（表单、表格、签名）。

### 核心功能

| 功能 | 描述 |
|------|------|
| **OCR** | 从图像/PDF 中提取文字，保留布局坐标 |
| **表格提取** | 识别并结构化提取表格数据 |
| **表单提取 (Key-Value)** | 提取表单字段和对应值 |
| **签名检测** | 检测文档中的签名位置 |
| **费用单识别** | 专门识别收据/发票的预定义模型 |
| **文档查询** | 对 OCR 后的内容进行自然语言查询 |

### 支持格式

- JPEG、PNG、PDF、TIFF

### 适用场景

```
场景分析 → 使用 Textract
├── "数字化纸质申请表" → 表单提取
├── "自动录入发票数据" → 费用单识别
├── "验证合同是否有签名" → 签名检测
└── "在大量文档中查找特定信息" → OCR + 文档查询
```

## Amazon Lex（对话 AI / 聊天机器人）

> **Amazon Lex** 是构建对话式语音和文字聊天机器人的服务，是 Alexa 的商业/企业版本。

### 核心特性

| 特性 | 描述 |
|------|------|
| **自动语音识别 (ASR)** | 将语音转换为文字 |
| **自然语言理解 (NLU)** | 理解用户意图 |
| **意图 (Intent)** | 用户想要完成的操作 |
| **槽位 (Slot)** | 完成意图所需的参数信息 |
| **多轮对话** | 支持上下文感知的多轮会话 |

### 典型架构

```
用户语音/文字 → Amazon Lex（意图识别）→ Lambda 函数（业务逻辑）→ 后端系统
```

## Amazon Kendra（企业搜索）

> **Amazon Kendra** 是企业级机器学习搜索引擎，使用语义和上下文理解（而非简单关键词匹配）进行搜索。

### 核心特性

| 特性 | 描述 |
|------|------|
| **语义搜索** | 理解问题含义，而非关键词匹配 |
| **自然语言问答** | 直接回答问题，而非返回文档列表 |
| **多数据源连接** | 支持 S3、SharePoint、Salesforce、数据库等 |
| **访问控制** | 基于用户权限过滤搜索结果 |

### 与 RAG（Bedrock Knowledge Bases）对比

| 特性 | Amazon Kendra | Bedrock Knowledge Bases |
|------|--------------|------------------------|
| **技术** | 传统搜索 + ML 语义 | 向量嵌入 + LLM |
| **输出** | 相关文档/段落 | LLM 生成的自然语言答案 |
| **适合场景** | 企业文档搜索 | 生成式 AI 应用 RAG |

## Amazon Personalize（推荐系统）

> **Amazon Personalize** 是全托管的个性化推荐服务，使用与 Amazon.com 相同的技术。

### 核心数据集

| 数据集 | 必填 | 说明 |
|--------|------|------|
| **用户-物品交互数据** | ✅ 必填 | 用户 ID、物品 ID、时间戳（核心） |
| **物品元数据** | 可选 | 物品的属性（类别、价格等） |
| **用户元数据** | 可选 | 用户属性（年龄、地区等） |

### 推荐场景

| 推荐类型 | 描述 |
|---------|------|
| **用户个性化** | 为特定用户推荐内容 |
| **相关物品** | 与某物品相关的其他物品 |
| **热门商品** | 最受欢迎的物品 |
| **最近浏览** | 基于用户最近行为 |

## Amazon Polly（文字转语音）

> **Amazon Polly** 将文本转换为逼真语音，支持 SSML 标记语言进行精细控制。

### SSML 支持

| 标签 | 功能 |
|------|------|
| `<speak>` | 根元素 |
| `<break>` | 插入停顿 |
| `<emphasis>` | 强调语气 |
| `<prosody>` | 控制音量、语速、音调 |
| `<whisper>` | 低声说话效果（仅特定声音） |
| `<lang>` | 切换语言 |

## Amazon Transcribe（语音转文字）

> **Amazon Transcribe** 是自动语音识别 (ASR) 服务，将音频转换为文字。

| 功能 | 描述 |
|------|------|
| **实时转录** | 实时流式转录 |
| **批量转录** | 异步处理音频文件 |
| **说话人识别** | 区分多个说话人 |
| **自定义词汇** | 添加专业术语提高识别准确率 |
| **PII 编辑** | 自动从转录文字中移除个人信息 |

---

## Amazon Fraud Detector（欺诈检测）

> **Amazon Fraud Detector** 是全托管的实时欺诈检测服务，使用 ML 识别潜在欺诈行为。

- 适用场景：在线支付欺诈、账户盗用、虚假注册
- 无需 ML 专业知识，上传历史数据即可训练模型

---

## Amazon Q / CodeWhisperer（AI 编码）

> **Amazon Q** 是 AWS 的企业 AI 助手，**CodeWhisperer** 是 VS Code / JetBrains 中的 AI 代码建议工具（现已整合入 Amazon Q Developer）。

| 产品 | 场景 |
|------|------|
| **Amazon Q Business** | 企业内部知识问答助手 |
| **Amazon Q Developer** | 代码生成、代码审查、bug 修复建议 |
